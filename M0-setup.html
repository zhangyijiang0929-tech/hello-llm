2Git：修掉残留锁并完成首次提交 需要你执行

这台机器上 Git 2.39.5 已装、全局身份我已配好（yzha1507）。但项目里有个残留的 .git/HEAD.lock，我的会话被安全策略禁止删除文件，所以下面三条要你自己敲。

cd ~/WorkBuddy/hello-llm
rm -rf .git f05usk5j thlnytbs k21c0wuv
git init -b main
git add -A && git commit -m "docs: add hello-llm with first API call"
为什么敢删 .git：这个目录是我刚才初始化失败留下的半成品，里面没有任何提交记录，删掉不损失任何东西。第一次提交完成后，git log --oneline 应看到一行。

3Docker Desktop 需要你执行

讲义要求「一条 docker run 就能跑」。你选的是 Docker Desktop，Apple Silicon 用 arm64 安装包。

# 方式一：Homebrew（推荐，一条命令）
brew install --cask docker

# 方式二：手动下载
open https://desktop.docker.com/mac/main/arm64/Docker.dmg

装完必须手动启动一次 Docker 应用（菜单栏出现鲸鱼图标），首次启动会要求授权系统助手，按提示输入密码。然后验证：

docker --version
docker run --rm hello-world
macOS 27 是预发布版，如果启动后提示「无法验证开发者」，去 系统设置 → 隐私与安全性 → 仍要打开。若 docker 命令找不到，把 /Applications/Docker.app/Contents/Resources/bin 加到 PATH。

5第一次调用 LLM（免费路线：本地 Ollama） 需要你执行

你没有 Anthropic Key，所以先用本地模型跑通同样的流程。代码已写好：hello_local.py 用 urllib 直接 POST 一个 HTTP 接口——这正是讲义 0.4「HTTP 与 REST」的实操。

brew install ollama
ollama serve                 # 保持这个终端开着
# 另开一个终端：
ollama list                  # 先看本机已有哪些模型（你这台已有 qwen2.5:1.5b）

cd ~/WorkBuddy/hello-llm
.venv/bin/python hello_local.py
你这台机器已有 qwen2.5:1.5b 和 deepseek-r1:1.5b，脚本默认用前者，无需再下载。想换模型：export OLLAMA_MODEL=deepseek-r1:1.5b。脚本会自动检测已装模型，指定的模型不存在时退回第一个可用的。

6推到 GitHub（M0 真正的产出） 需要你执行

SSH 我已经验过：git@github.com 认到账号 yzha1507，可以直接推，不用再配密钥。

# 1. 浏览器里新建空仓库（不要勾选 README / .gitignore）
open "https://github.com/new?name=hello-llm&visibility=public"

# 2. 加远端并推送
cd ~/WorkBuddy/hello-llm
git remote add origin git@github.com:yzha1507/hello-llm.git
git push -u origin main
推送前最后一道检查：git ls-files | grep -i env 只应出现 .env.example。真实 key 一旦进过提交，就必须吊销重发。
